# Ethara.AI-Team-Task-Manager
TaskFlow is a full-stack web application that allows users to manage projects, assign tasks, and track progress with role-based access control. It is designed with a modern UI and a scalable backend architecture.
Features
🔐 Authentication
Secure Signup/Login using JWT
Token-based session handling
👥 Role-Based Access
Admin & Member roles
Controlled permissions
📁 Project Management
Create and view projects
Assign ownership
✅ Task Management
Create tasks
Assign to users
Track status
📊 Dashboard
View tasks dynamically
Real-time updates from backend
🎨 Modern UI
Apple-style clean interface
Responsive design
🛠️ Tech Stack
Frontend
React (Vite)
Axios
React Router
Backend
Node.js
Express.js
JWT Authentication
LowDB (JSON Database)
